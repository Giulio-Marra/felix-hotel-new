# Felix Hotel

Rifacimento di un mio vecchio progetto (circa 2 anni fa): un gestionale
per hotel, con parte **backoffice** (gestione interna) e parte
**frontoffice** (lato cliente).

Questa volta il progetto viene sviluppato usando **Claude** come
assistente/agente di sviluppo, seguendo un workflow definito: è anche
un esperimento per capire come un'AI gestisce in autonomia lo sviluppo
di un progetto reale, dalla progettazione al codice.

## Stack

- **Backend**: Java + Spring Boot, API documentate con Swagger/OpenAPI
- **Frontend**: React

## Struttura del repository

```
felix-hotel-new/
├── backend/    # progetto Spring Boot
├── frontend/   # progetto React
└── docs/       # documentazione e file condivisi tra backend e frontend
```

## Stato del progetto

Progetto agli inizi: setup della struttura in corso. Dettagli e log di
avanzamento in [`docs/CLAUDE.md`](docs/CLAUDE.md).
